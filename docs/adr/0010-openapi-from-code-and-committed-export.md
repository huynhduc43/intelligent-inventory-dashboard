# OpenAPI is generated from code, served at `/docs` and exported by a script

`@nestjs/swagger` 12 builds the document from the controllers. Zod request schemas reach it through `@Body({ schema })` with no extra decorators; the one hand-registered component is `Problem`, derived from a zod `problemSchema` in `shared/problem.ts` so the error shape has a single source. `setupDocs(app)` serves Swagger UI at `/docs` and the JSON at `/docs-json`, and `main.ts` alone calls it, so the integration tests do not mount it. `docs/api/openapi.json` is written by a script that creates the app without listening, so export needs no free port, and a test regenerates the document and compares it with the committed file, so it cannot go stale. Bearer auth is documented per protected route, because the global `JwtAuthGuard` leaves login and health public. `/health/*` stays outside `/api/v1` and is documented where it is. Rejected: `GET /docs-json` on a running app (needs a port and a live DB), the Nest CLI swagger plugin (it reads DTO classes, and this repo has none) and `nestjs-zod` (a second pipe and dependency for what Standard Schema already does). Extends §4.7 ("OpenAPI at `/docs`"); supersedes nothing.
